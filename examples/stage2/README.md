# Данные второй ступени

Все данные и бренд «Северный ветер» **синтетические**. Числа придуманы для
проверки конвейера; они не описывают VK Tech, реальный магазин или клиентов.
Организаторские шаблоны в `tests/fixtures/pptx/` используются как тестовые
фикстуры. Сервис принимает и незнакомые шаблоны.

| Файл | Что проверяет | Ожидаемое объяснение выбора |
|---|---|---|
| `purchases.csv` | Покупки интернет-магазина за 730 дней, пропуски региона и канала | Сумма по месяцам → линия; сравнение категорий и регионов → столбцы |
| `sales_monthly.csv` | Выручка за 24 месяца | Порядок времени и одна метрика → линия |
| `sales_monthly.xlsx`, `sales_monthly.json` | Те же значения в других форматах, шапка XLSX ниже заголовка | Тип графика совпадает с CSV |
| `regions.xlsx` | Категории, две метрики | Сравнение регионов, горизонтальные или группированные столбцы |
| `channels_share.json` | Небольшое число долей | Признак структуры → круговая/кольцевая; столбцы как альтернатива |
| `order_values.csv` | 600 сумм заказов, длинный хвост | Распределение → гистограмма с бинами |
| `products_reference.xlsx` | Справочник из 240 строк | Нет одной доминирующей метрики → таблица, сводка и продолжения |
| `nps_with_gaps.csv` | Временной ряд с пропусками | Линия с разрывами, раскрытие отсутствующих периодов |
| `report_with_table.txt` | Текст и таблица внутри, цель «показать рост» | Текст задаёт намерение, таблица становится временным рядом |
| `ad_spend_vs_sales.csv` | 40 пар расходов и продаж | Взаимосвязь → рассеяние; корреляция не доказывает причинность |
| `kpi.json` | Небольшой набор подписанных значений | KPI-карточки |
| `brandbook/tokens.json` | Палитра и шрифты бренда | Брендбук перекрывает стиль шаблона, типы графиков сохраняются |
| `brandbook/figma_variables.json` | Те же роли цветов через экспорт Figma | Офлайн-приём экспорта без доступа к Figma |
| `brandbook/guideline.pdf`, `brandbook/logo.png` | PDF-гайдлайн и логотип | Извлечение правил из текста PDF, ассет логотипа |

Доли каналов в `channels_share.json` не следует сравнивать с долями в
`purchases.csv`: это отдельные синтетические примеры с разными числами.
Пропуски явно раскрываются в источнике и выводах, неизвестные значения
не считаются нулевыми продажами.

## Пересоздание

Из корня репозитория, без модели и веб-поиска:

```bash
PYTHONPATH=backend .venv/bin/python scripts/make_stage2_data.py
PYTHONPATH=backend .venv/bin/python scripts/make_stage2_brandbook.py
```

Генератор данных использует фиксированный seed. Табличные значения
воспроизводимы; ZIP/PDF-метаданные и время записи файлов могут отличаться.
Для PDF/PNG генератора брендбука нужны `reportlab`, Pillow и доступный шрифт
Play из `assets/fonts/play/Play-Regular.ttf` (включён в репозиторий,
лицензия OFL). Для другого шрифта есть `--font /path/font.ttf`.
Для проверки без перезаписи фикстур оба генератора принимают
`--out /tmp/stage2-data` и `--out /tmp/stage2-brand` соответственно.

## Проверка

```bash
PYTHONPATH=backend .venv/bin/python scripts/benchmark_viz.py --json /tmp/stage2-benchmark.json
PYTHONPATH=backend .venv/bin/python scripts/stage2_render_check.py --out /tmp/stage2-render
PYTHONPATH=backend .venv/bin/python scripts/brand_render_check.py --out /tmp/stage2-brand
```

Рендер требует LibreOffice и `pdftoppm`. Скрипты запускаются последовательно.
В отчётах раздельно проверяются корректность выбора типа графика, соблюдение фирменного стиля и чистота рендера.
